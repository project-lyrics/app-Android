# 로그인 화면 구동 플로우

- 소셜 로그인 버튼은 누른 즉시 회원가입 화면으로 이동
- 하단의 비로그인 진입 기능을 이용해 홈 화면으로 이동

# 회원가입 화면 구동 플로우

- 약관 동의 -> 성별 화면 순으로 이동
- 데이터는 화면에서만 지정하며 필요한 요소에 데이터 입력이 완료되면 다음 화면으로 이동
- 성별 화면의 데이터 선택이 완료되면 홈 화면으로 이동

# 참고 사항

- 화면 이동만을 구현하며, 별도의 데이터 처리는 고려하지 않음

# 제약 사항

- 멀티모듈을 고려한 구글 앱 아키텍처 방식
  - core 모듈과 feature 모듈의 차이를 유념
- `implementation_plan.md` 파일에 작업 단계를 상세히 기록
